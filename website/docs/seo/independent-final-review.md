## Findings and remaining limits

**P2 — End-to-end measurement is only partially established.** The [analytics acceptance report](analytics-acceptance.md) and its sanitized evidence agree: explicit consent produced page views; one real ZIP-link click produced exactly one `download_click`; Google accepted that event and one genuine LCP event with HTTP 204. Default-off behavior, custom-payload redaction, non-download controls, refresh, and withdrawal passed the exercised checks. However, CLS and INP delivery were unobserved, Realtime still showed no data, one observed page view lacked a response receipt, and six lifecycle requests reported `net::ERR_ABORTED`. These observations do not establish a source-code defect, but they do prevent claiming complete or lossless reporting. The next useful action is the bounded provider-report check already scheduled, not synthetic metrics or repeated test traffic.

**P2 — Search-engine completion remains external and time-dependent.** [Account evidence](account-setup.md) establishes Google and Bing ownership, Google's successful six-page sitemap read, representative Google live indexability/schema acceptance, and the effective AI setting of Include. It does not establish indexing: the inspected URLs were discovered but not indexed, and a manual request hit quota. Bing's sitemap submission returned a server error without receipt. IndexNow acknowledgment is not a substitute for either engine's indexing result.

**P3 — Some operational evidence cannot yet exist or remains incomplete.** The 14-day checkpoints are scheduled rather than completed. Comparable search traffic, a representative field Core Web Vitals distribution, and actual access by every desired AI/search crawler are unestablished. A firewall API failure was correctly retained as a limit instead of treated as proof. The [checklist](launch-checklist.md) preserves these distinctions.

I found **no material actionable defect in the reviewed website or analytics source**. The independent review's documentation findings—stale account actions, an overbroad dependency statement, outdated LCP wording, and the absent effective AI-setting record—were corrected during this follow-up. No further implementation repair is recommended solely to obtain a higher score.
